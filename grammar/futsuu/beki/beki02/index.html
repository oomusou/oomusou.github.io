べき (應該)

2026-07-17

普通形 べき 名詞 可表示 義務 上的 應該，或 建議上的應該，此時相當於 たほうがいい，但語氣上較 強烈。翻譯成 應該。

難度

  • N2

情境

用於 修飾名詞，表達該名詞應該具備的 義務 或 建議 性質。

接続

  • 普 + べき + N
  • V普 + べき + N / 動III る + N
  • いA い + くある + べき + N
  • なA + である + べき + N
  • N + である + べき + N

動詞

これは誰もが守るべきルールだ。

這是任何人都應該遵守的規則。

  • これ [0]：代 這個
  • は：副助 表 主題
  • 誰(だれ)もが [1]：連語 任何人都
  • 守(まも)る [0]：動I 他動 辞書形 遵守
    • 守るべき [0]：應該 應該遵守
    • 守るべきルール [0]：應該 應該遵守的規則
  • ルール [1]：名 規則
  • だ：助動 斷定

これは今すぐ実行するべき対策だ。
これは今すぐ実行すべき対策だ。 (縮約)

這是應該立刻執行的對策。

するべき 可縮約成 すべき

  • これ [0]：代 這個
  • は：副助 表 主題
  • 今(いま)すぐ [1]：副 立刻
  • 実行(じっこう)する [0]：動III 他動 辞書形 執行
    • 実行するべき対策(たいさく) [1]：應該 應該執行的對策
    • 実行すべき対策(たいさく) [1]：縮約 應該執行的對策
  • 対策(たいさく) [0]：名 對策
  • だ：助動 斷定

い形容詞

彼は若くあるべき姿勢を大切にしている。

他很重視年輕人應該有的態度。

  • 彼(かれ) [1]：代 他
  • は：副助 表 主題
  • 若(わか)い [2]：い形容 年輕的
    • 若くあるべき [2]：應該 應該年輕
    • 若くあるべき姿勢(しせい) [2]：應該 應該年輕的態度
  • 姿勢(しせい) [0]：名 態度
  • を：格助 接受 大切にする 的 賓語
  • 大切(たいせつ)にする [0]： 慣 重視
    • 大切にして [0]：て形 重視
    • 大切にしている [0]：狀態 重視著

な形容詞

私たちは公平であるべき社会を目指している。

我們正在以理應公平的社會為目標。

  • 私(わたし)たち [0]：代 我們
  • は：副助 表 主題
  • 公平(こうへい) [0]：な形容 公平的
    • 公平であるべき(かいしゃ) [0]：應該 應該公平
    • 公平であるべき会社(かいしゃ) [0]：應該 應該公平的社會
  • 社会(しゃかい) [0]：名 社會
  • を：格助 接受 目指す 的 賓語
  • 目指(めざ)す [2]：動I 他動 以 為目標
    • 目指して [2]：て形 以 為目標
    • 目指している [2]：現在進行 以 為目標

名詞

彼は理想であるべき教師を目指している。

他正以成為理想中的老師為目標。

  • 彼(かれ) [1]：代 他
  • は：副助 表 主題
  • 理想(りそう) [0]：名 理想
    • 理想であるべき [0]：應該 應該是理想
    • 理想であるべき教師(きょうし) [1]：應該 應該是理想老師
  • を：格助 接受 目指す 的 賓語
  • 目指(めざ)す [2]：動I 他動 以 為目標
    • 目指して [2]：て形 以 為目標
    • 目指している [2]：狀態 以 為目標
