をきっかけにして (以 爲契機)

2026-05-09

名詞 をきっかけにして 可表示某件事情成為 引發後續變化、行動 或 想法 的 原因。常用於描述 人生轉變、開始學習新事物、改變習慣 或 事件 帶來的影響。翻譯成 以 爲契機。

接続

  • V普 + の/こと + をきっかけにして
  • N + をきっかけにして

動詞

病気になったことをきっかけにして、生活習慣を見直した。

生病這件事，成為我重新審視生活習慣的契機。

をきっかけして 的 漢字 為 切っ掛け，語源 為名詞的 切り掛け，其動詞為 切り掛ける，源自於 切る + 掛ける，本意是 開始切入的點，衍生為 以 爲契機

  • 病気(びょうき) [0]：名 生病
  • に：格助 表 變化結果
  • なる [1]：動I 自動 辞書形 變成
    • なった [1]：た形 變成了
    • なったこと [1]：名 變成了
    • なったことをきっかけにして [1]：以 爲契機 以生病爲契機
  • 生活習慣(せいかつしゅうかん) [5]：名 生活習慣
  • を：格助 接受 見直する 的 賓語
  • 見直(みなお)す [0]：動I 他動 辞書形 重新審視
    • 見直した [0]：た形 重新審視

名詞

日本旅行をきっかけにして、日本語の勉強を始めました。

以日本旅行為契機，我開始學日文。

  • 日本(にほん) [2]：名 日本
  • 旅行(りょこう) [0]：名 旅行
    • 旅行をきっかけにして [0]：以 爲契機 以旅行爲契機
  • 日本語(にほんご) [0]：名 日文
  • の：格助 表 所屬
  • 勉強(べんきょう) [0]：名 唸書
  • を：格助 接受 始める 的 賓語
  • 始(はじ)める [0]：動II 他動 辞書形 開始
    • 始めます [4]：ます形 開始
    • 始めました [4]：た形 開始
