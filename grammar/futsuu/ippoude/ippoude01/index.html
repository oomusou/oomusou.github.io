一方で (並列)

2026-05-20

普通形 一方で 可表示對於一個事物，有兩個 並列 的特性。翻譯成 一方面 另一方面。

接続

  • 普 + 一方で
  • V普 + 一方で
  • いA + 一方で
  • なA + な/である + 一方で
  • N + である + 一方で

動詞

AIは人々の仕事を助ける一方で、新しい働き方も生み出している。

人工智慧一方面幫助人們工作，另一方面也創造了新的工作方式。

  • AI [1]：名 人工智慧
  • 人々(ひとびと) [2]：名 人們
  • の：格助 表 所屬
  • 仕事(しごと) [0]：名 工作
  • を：格助 接受 助ける 的 賓語
  • 助ける(たすける) [3]：動II 他動 辞書形 幫助
    • 助ける一方(いっぽう)で [3]：並列 一方面幫助，另一方面
  • 新(あたら)しい [4]：い形容 新的
  • 働(はたら)き方(かた) [0]：名 工作方式
  • も：副助 表 也
  • 生(う)み出(だ)す [3]：動I 他動 創造
    • 生み出して [3]：て形 創造
    • 生み出している [3]：狀態 創造

い形容詞

この犬は大きい一方で、とても人懐っこい。

這隻狗一方面很大隻，另一方面也很親人。

  • この [0]：連体 這個
  • 犬(いぬ) [2]：名 狗
  • は：副助 表 主題
  • 大(おお)きい(おおきい) [3]：い形容 大的
    • 大きい一方(いっぽう)で [0]：並列 一方面大的，另一方面
  • とても [0]：副 非常
  • 人懐(ひとなつ)っこい [6]：い形容 親近人的

な形容詞

彼は真面目な一方で、とてもユーモアもある。

他一方面很認真，另一方面也很有幽默感。

  • 彼(かれ) [1]：代 他
  • は：副助 表 主題
  • 真面目(まじめ) [0]：な形容 認真的
    • 真面目な一方(いっぽう)で [0]：並列 一方面認真，另一方面
  • とても [0]：副 非常
  • ユーモア [1]：名 humor、幽默感
  • も：副助 表 也
  • ある [1]：動I 自動 有

名詞

彼は医者である一方で、小説家でもある。

他一方面是醫生，另一方面也是小說家。

  • 彼(かれ) [1]：代 他
  • は：副助 表 主題
  • 医者(いしゃ) [0]：名 醫生
    • 医者である一方(いっぽう)で [8]：並列 一方面是醫生，另一方面
  • 小説家(しょうせつか) [0]：名 小說家
  • でも [1]：副助 表 舉例
  • ある [1]：動I 自動 斷定
