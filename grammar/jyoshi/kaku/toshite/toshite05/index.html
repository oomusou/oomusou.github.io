として (判斷)

2026-07-19

接助詞 として 可表示 判斷，常用於 新聞，相當於 と判断して。

難度

  • N2

情境

用於 新聞報導 中，以某項 判斷 或 認定 為 理由，而採取後續行動時。

接続

  • 普 + として
  • V普 + として
  • いA + として
  • なA + だ + として
  • N + だ + として

動詞

警察は男が金を盗んだとして逮捕した。

警察判斷這名男子偷了錢而加以逮捕。

として 的 語源 為 とする 的 て形，本意為 把前項當作判斷的內容，引申為 判斷

  • 警察(けいさつ) [0]：名 警察
  • は：副助 表 主題
  • 男(おとこ) [3]：名 男子
  • が：格助 表 主語
  • 金(かね) [0]：名 錢
  • を：格助 接受 盗む 的 賓語
  • 盗(ぬす)む [2]：動I 他動 辞書形 偷
    • 盗んだ [2]：た形 偷了
    • 盗んだとして [5]：判斷 判斷偷了
  • 逮捕(たいほ) [1]：名 逮捕
    • 逮捕する [0]：動III 他動 辞書形 逮捕
    • 逮捕した [0]：た形 逮捕了

い形容詞

証拠が乏しいとして、不起訴となった。

判斷證據不足，而變成不起訴。

  • 証拠(しょうこ) [0]：名 證據
  • が：格助 表 主語
  • 乏(とぼ)しい [3]：い形容 缺乏的
    • 乏しいとして [6]：判斷 判斷缺乏
  • 不起訴(ふきそ) [2]：名 不起訴
  • と：格助 表 結果
  • なる [1]：動I 自動 辞書形 變成
    • なった [1]：た形 變成了

な形容詞

捜査が不十分だとして、批判された。

判斷搜查不夠充分，而受到了批判。

  • 捜査(そうさ) [1]：名 搜查
  • が：格助 表 主語
  • 不十分(ふじゅうぶん) [2]：な形容 不充分的
    • 不十分だとして [7]：判斷 判斷不充分
  • 批判(ひはん) [0]：名 批判
    • 批判する [0]：動III 他動 辞書形 批判
    • 批判された [2]：受身形 被批判

名詞

警察は彼を犯人だとして、捜査を進めた。

警察判斷他是犯人，而推進了搜查。

  • 警察(けいさつ) [0]：名 警察
  • は：副助 表 主題
  • 彼(かれ) [1]：代 他
  • を：格助 表 動作對象
  • 犯人(はんにん) [1]：名 犯人
    • 犯人だとして [6]：判斷 判斷是犯人
  • 捜査(そうさ) [1]：名 搜查
  • を：格助 接受 進める 的 賓語
  • 進(すす)める [0]：動II 他動 辞書形 推進
    • 進めた [0]：た形 推進了
