動詞意向形のアクセント

2022-08-22

動詞意向形 的 重音 統一在變形後 う 前面一個字。

動詞 I

い 段 -> お 段 + う

  • 買います [3] -> 買おう [2]
  • 歩きます [4] -> 歩こう [3]
  • 急ぎます [4] -> 急ごう [3]
  • 直します [4] -> 直そう [3]
  • 待ちます [3] -> 待とう [2]
  • 遊びます [4] -> 遊ぼう[3]
  • 休みます [4] -> 休もう [3]
  • 乗ります [3] -> 乗ろう [2]

動詞 II

え 段 -> よう

  • 換えます [3] -> 換えよう [3]
  • 覚えます [3] -> 覚えよう [3]
  • 見ます [2] -> 見よう [2]

動詞 III

  • 来(き)ます [2] -> 来(こ)よう [2]
  • します [2] -> しよう [2]
  • 勉強します [6] -> 勉強しよう [6]
