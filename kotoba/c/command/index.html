命令

2026-08-29

命令 可用 てください、てちょうだい、ておいで、て、なさい、てくれ 或 命令形 表示。

難度

  • N4

情境

用於依照與對方的 關係、場合 及 命令強度，提出 請求、指示、催促 或 強制 要求對方採取行動。

接続

  • Vて + ください
  • Vて + ちょうだい
  • Vて + おいで
  • Vて
  • Vます ます + なさい
  • Vて + くれ
  • Vえ

てください

食べてください。

請吃。

てください 是 最常用 的 禮貌請求 句型，使用 て形 要求或請對方做某事；雖然比其他命令說法客氣，但對 上位者 仍可能顯得 直接

  • 食(た)べる [2]：動II 他動 辞書形 吃
    • 食べて [1]：て形 吃
    • 食べてください [3]：請託 請

てちょうだい

食べてちょうだい。

吃一下吧。

てちょうだい 是比 てください 更 隨意 的請求，常用於親近 的人之間或 上對下，帶有 柔和 語感，但 不適合正式場合

  • 食(た)べる [2]：動II 他動 辞書形 吃
    • 食べて [1]：て形 吃
    • 食べてちょうだい [3]：請託 請幫我吃

ておいで

食べておいで。

去吃吧。

ておいで 是帶有 親切 語氣的指示，表示要對方去做某事後再回來，常由 長輩 對 晚輩 或 關係親近 者使用

  • 食(た)べる [2]：動II 他動 辞書形 吃
    • 食べて [1]：て形 吃
    • 食べておいで [0]：溫柔命令 去吃吧

て

食べて。

吃吧。

句尾只使用 て形 可表示 隨意 而 直接 的請求，常用於 家人 或 朋友之間，語調 柔和 時像請求，語調 強硬 時則接近命令

  • 食(た)べる [2]：動II 他動 辞書形 吃
    • 食べて [1]：て形 吃吧

なさい

食べなさい。

吃下去。

なさい 是 上對下 的指示或命令，常由 父母、教師 等對 晚輩 使用，比 命令形 稍柔和，但 不能 用來命令 上位者

  • 食(た)べる [2]：動II 他動 辞書形 吃
    • 食べます [3]：ます形 吃
    • 食べなさい [4]：命令 吃下去

てくれ

食べてくれ。

給我吃。

てくれ 原本表示要求對方為自己做某事，作為命令時語氣 直接 而 粗獷，常見於 男性口語、同輩 之間或 緊急情況

  • 食(た)べる [2]：動II 他動 辞書形 吃
    • 食べて [1]：て形 吃
    • 食べてくれる [0]：動II 他動 辞書形 為我做
    • 食べてくれ [1]：命令形 給我

命令形

食べろ。

吃！

命令形 直接 強制 對方行動，語氣 強烈，日常 使用容易顯得 粗魯，主要見於 緊急狀況、軍隊口令、比賽助威 或 親密關係 中的 強硬說法

  • 食(た)べる [2]：動II 他動 辞書形 吃
    • 食べろ [2]：命令形 吃

まとめ

  • 強度：てちょうだい / ておいで -> てください / て -> なさい -> てくれ -> 命令形
  • 禮貌度：てください -> てちょうだい／ておいで -> なさい／て -> てくれ -> 命令形
