相槌 可用 うん、そうそう 或 そうなんだ …等字表示。

単語

  • うん [1]：感 嗯、是啊 (最基本，同輩間最常用)
  • うんうん [1]：感 嗯嗯、對對 (加強版、表示認真在聽)
  • そうそう [1]：感 對對、就是那樣 (強烈認同)
  • そうなんだ：慣用語 原來如此、是這樣啊
  • わかる [2]：動I 自動 我懂、能理解 (表示認同、有共鳴)
  • ほうほう [1]：感 哦哦 (表示好奇、感興趣的語感)
  • ふん [1]：感 嗯哼 (隨意、有點漫不經心的附和)
  • へー [0]：感 欸～ (表示驚訝、新奇)
  • 本当(ほんとう)？ [0]：慣用語 真的？
  • 本当(ほんとう)に？ [0]：慣用語 真的假的？
  • まじ？ [1]：慣用語 真的假的？(驚訝)
  • なるほど [0]：副 原來如此
  • はい [1]：感 是
  • ええ [1]：感 是的 (比はい更柔和)
  • そうですね：慣用語 說得也是 (表示認同，最萬用)
  • なるほどですね：慣用語 原來如此呢
  • おっしゃる通(とお)りです：慣用語 您說的沒錯 (正式場合，表示高度認同)
  • 勉強(べんきょう)になります：慣用語 獲益良多 (正式場合，表示對方的話很有價值)
  • 存(ぞん)じております：謙讓語 我知道 (表示自己已經知情)

朋友

うん

うん、わかった。

嗯，我知道了。

うん 是 隨意 的肯定回應，適合 親近 的 朋友、家人或 晚輩，不宜 對 長輩、客戶 使用

  • うん [1]：感 嗯、是啊
  • わかる [2]：動I 自動 辞書形 知道
    • わかった [2]：た形 知道了

うんうん

うんうん、その気持ち、わかるよ。

嗯嗯，那種心情我懂喔。

重複的 うんうん 比 うん 更能表現 一邊聽、一邊贊同 或 理解對方 的語感

  • うんうん [1]：感 嗯嗯、對對
  • その [0]：連体 那個
  • 気持(きも)ち [0]：名 心情
  • わかる [2]：動I 自動 懂、理解
  • よ：終助 表 強調

そうそう

そうそう、私も同じことを思ってた。

對對，我也在想同一件事。

そうそう 用來 強烈贊同 對方，或表示對方 正好說出自己想表達 的內容

  • そうそう [1]：感 對對、就是那樣
  • 私(わたし) [0]：代 我
  • も：副助 也
  • 同(おな)じ [0]：連体 相同的
  • こと [2]：名 事情
  • を：格助 接受 思う 的 賓語
  • 思(おも)う [2]：動I 他動 辞書形 想、認為
    • 思って [2]：て形 想、認為
    • 思っている [2]：現在進行 現在正在想
    • 思っていた [2]：過去進行 當時正在想
    • 思ってた [2]：縮約 當時正在想

そうなんだ

そうなんだ、それは大変だったね。

原來是這樣，那真是辛苦了呢。

そうなんだ 表示剛得知對方所說的事，帶有 理解、意外 或 關心 的語感

  • そうなんだ：慣 原來如此、是這樣啊
  • それ [0]：代 那件事
  • は：係助 表 主題
  • 大変(たいへん) [0]：な形容 辛苦的
  • だ：助動 斷定
    • だった：た形 斷定
  • ね：終助 表 共感

わかる

わかる、私もそう思う。

我懂，我也這麼覺得。

單獨說 わかる 表示自己 能理解 或 認同 對方的感受，語氣較 隨意

  • わかる [2]：動I 自動 懂、理解
  • 私(わたし) [0]：代 我
  • も：副助 也
  • そう [0]：副 那樣
  • 思(おも)う [2]：動I 他動 認為

ほうほう

ほうほう、それでどうなったの？

哦哦，然後變成怎樣了？

ほうほう 表示 感興趣 並催促對方 繼續說，常用於 輕鬆對話

  • ほうほう [1]：感 哦哦、原來如此
  • それで [0]：接続 然後
  • どう [1]：副 如何
  • なる [1]：動I 自動 辞書形 變成
    • なった [1]：た形 變成了
    • なったの [1]：終助 表 疑問

ふん

ふん、なるほどね。

嗯，原來如此呢。

ふん 可表示 聽懂後 的 低聲回應，但 語調較強 時會成為不滿或輕蔑的 哼，使用時要 注意語氣

  • ふん [1]：感 嗯；哼
  • なるほど [0]：副 原來如此
  • ね：終助 表 共感

へー

へー、そんな方法があるんだ。

哦，原來有那種方法啊。

へー 用來表達 驚訝 或 興趣，拖長音可加強 第一次聽說 的感覺

  • へー [0]：感 哦、是喔
  • そんな [0]：連体 那樣的
  • 方法(ほうほう) [0]：名 方法
  • が：格助 表 主語
  • ある [1]：動I 自動 有、存在

本当？

本当？それは知らなかった。

真的嗎？那件事我不知道。

本当？ 是口語的 反問，用來表示 驚訝 並 確認 消息是否屬實

  • 本当(ほんとう) [0]：名 真的
  • それ [0]：代 那件事
  • は：係助 表 主題
  • 知(し)る [0]：動I 他動 辞書形 知道
    • 知らない [0]：ない形 不知道
    • 知らなかった [0]：た形 原本不知道

本当に？

本当に？ずっと冗談だと思ってた。

真的嗎？我一直以為是在開玩笑。

本当に？ 比 本当？ 稍 完整，但在 朋友間 仍是自然的 口語 說法

  • 本当(ほんとう)に [0]：副 真的
  • ずっと [0]：副 一直
  • 冗談(じょうだん) [3]：名 玩笑
  • だ：助動 斷定
  • と：格助 表 內容
  • 思(おも)う [2]：動I 他動 辞書形 以為
    • 思って [2]：て形 以為
    • 思っている [2]：習慣反覆 一直以為
    • 思っていた [2]：た形 當時一直以為
    • 思ってた [2]：縮約 當時一直以為

まじ？

まじ？そんなの信じられない。

真的假的？那種事令人難以置信。

なるほど

原來如此，我充分理解了。

なるほど 表示聽過說明後 理解 並 接受其道理，但對 上位者 直接說有時會顯得像在 評判對方

はい 是 標準 且 禮貌 的應答，可表示自己 正在聽、同意 或 已理解，正式場合比 うん、ええ 更穩妥

  • はい [1]：感 是的

    • 承知する [0]：動III 他動 辞書形 知道
    • 承知します [0]：ます形 知道
    • 承知しました [0]：た形 知道了

ええ

是的，照那個安排沒有問題。

ええ 是比 うん 更 禮貌 的 肯定回應，可用於 一般成人 對話，但 正式 應答使用 はい 更穩妥

  • ええ [1]：感 是的、嗯

  • です [0]：助動 斷定
