無糖 可用 無糖、糖類ゼロ、砂糖不使用 或 糖質ゼロ 表示，但 意義 不太一樣。

難度

  • N2

情境

用於閱讀 日本食品 或 飲料 的標示，以及區分 不含糖類、未添加砂糖 與 不含糖質 等不同概念。

単語

  • 無糖(むとう) [0]：名 無糖
  • 糖類(とうるい) [1]：名 葡萄糖、果糖 、蔗糖、乳糖 等 單糖 或 雙糖
  • 砂糖(さとう) [2]：名 砂糖
  • 糖質(とうしつ) [0]：名 炭水化物 − 食物繊維

無糖

健康のため、毎朝、無糖のコーヒーを飲んでいます。

為了健康，我每天早上都喝無糖咖啡。

無糖 通常屬於 糖類幾乎不含有 這類營養強調標示，需要符合日本食品標示中可以標示為 0 的相關基準，並不是 單純表示製造時 沒加砂糖

糖類ゼロ

この飲料は糖類ゼロですが、糖質もゼロだとは限りません。

這款飲料雖然是零糖類，但糖質不一定也是零。

糖類ゼロ 和 無糖 一樣，看的都是 糖類，也必須符合 不含有 的標示基準。這裡的糖類(とうるい)，主要指 葡萄糖、果糖、蔗糖、乳糖 等 單糖 或 雙糖，不等於所有的 碳水化合物

砂糖不使用

砂糖不使用のジャムでも、果物由来の糖類が含まれていることがあります。

即使是未使用砂糖的果醬，也可能含有來自水果的糖類。

砂糖不使用 不是 糖類為零，而是屬於 沒有添加糖類 的標示。依日本的食品標示規定，必須符合沒有添加糖類等相關條件，但 食品原料 本身原有的 糖類 仍可能 存在

糖質ゼロ

糖質を控えているので、糖質ゼロの商品を選びました。

因為我正在控制糖質攝取，所以選了零糖質的商品。

日本食品標示中的 糖質 和 糖類 範圍不同。簡單理解，糖質 是 碳水化合物 中扣除 食物纖維 等之後的部分；糖類 只是其中 更小的一類

まとめ

  • 無糖：糖類 很少，但仍可能含 碳水化合物，未必不升血糖
  • 糖類ゼロ： 糖類 很少，但仍可能含 碳水化合物，未必不升血糖
  • 砂糖不使用：未添加砂糖，但仍可能含 碳水化合物，未必不升血糖
  • 糖質ゼロ： 完全 不含碳水化合物，是 真無糖，不會升血糖
