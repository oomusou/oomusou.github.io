見的複合動詞

2026-09-14

6 個常用 見 的 複合動詞。

難度

  • N1

情境

用於區分含有 見 的常用 複合動詞，表達 偶然看到、找到、找不到、看漏、重新檢視 或 目送與暫緩 等不同情境。

単語

  • 見(み)かける [0]：動II 他動 偶然看到
  • 見(み)つける [0]：動II 他動 找到、發現
  • 見当(みあ)たらない [0]：動I 自動 ない形 找不到、沒看到
  • 見落(みお)とす [0]：動I 他動 看漏、忽略
  • 見直(みなお)す [0]：動I 他動 重新檢查、重新審視、重新評價
  • 見送(みおく)る [0]：動I 他動 目送、暫緩、放棄

見かける

街で昔の友達を見かけた。

在街上偶然看到了以前的朋友。

見かける 表示並 非刻意尋找，而是 偶然進入視線

  • 街(まち) [2]：名 街上
  • で：格助 表 發生場所
  • 昔(むかし) [0]：名 以前
  • の：格助 表 修飾
  • 友達(ともだち) [0]：名 朋友
  • を：格助 接受 見かける 的 賓語
  • 見(み)かける [0]：動II 他動 辞書形 偶然看到
    • 見かけた [0]：た形 偶然看到了

見つける

公園でなくした鍵を見つけた。

在公園找到了遺失的鑰匙。

見つける 強調經過 尋找 或 察覺 後 找到 對象

  • 公園(こうえん) [0]：名 公園
  • で：格助 表 發生場所
  • なくす [0]：動I 他動 辞書形 遺失
    • なくした [0]：た形 遺失了
  • 鍵(かぎ) [2]：名 鑰匙
  • を：格助 接受 見つける 的 賓語
  • 見(み)つける [0]：動II 他動 辞書形 找到
    • 見つけた [0]：た形 找到了

見当たらない

財布がどこにも見当たらない。

錢包哪裡都找不到。

見当たらない 表示目標沒有出現在 視線 或目前可確認的 範圍 內，不一定 表示已仔細尋找

  • 財布(さいふ) [0]：名 錢包
  • が：格助 表 主語
  • どこ [1]：代 哪裡
  • に：格助 表 存在位置
  • も：副助 表 全面否定
  • 見当(みあ)たる [0]：動I 自動 辞書形 看到
    • 見当たらない [0]：ない形 沒看到

見落とす

書類の重要なミスを見落としてしまった。

不小心看漏了文件中的重要錯誤。

見落とす 表示本應注意到，卻因疏忽而 漏看 或 忽略

  • 書類(しょるい) [0]：名 文件
  • の：格助 表 修飾
  • 重要(じゅうよう) [0]：な形容 重要的
  • な：助動 以 な形容詞 修飾 名詞
  • ミス [1]：名 錯誤、失誤
  • を：格助 接受 見落とす 的 賓語
  • 見落(みお)とす [0]：動I 他動 辞書形 看漏
    • 見落として [0]：て形 看漏
    • 見落としてしまう [0]：遺憾 不小心看漏
    • 見落としてしまった [0]：た形 不小心看漏了

見直す

提出前に、書類の内容を見直した。

提交前，重新檢查了文件的內容。

見直す 表示 再看一次，可指 重新檢查、重新審視 或 重新評價

  • 提出(ていしゅつ) [0]：名 提交
  • 前(まえ) [1]：名 之前
  • に：格助 表 時間點
  • 書類(しょるい) [0]：名 文件
  • の：格助 表 所屬
  • 内容(ないよう) [0]：名 內容
  • を：格助 接受 見直す 的 賓語
  • 見直(みなお)す [0]：動I 他動 辞書形 重新檢查
    • 見直した [0]：た形 重新檢查了

見送る

駅で友達を見送った。

我在車站目送朋友離開。

見送る 原指看著某人離去的 目送，也可表示因時機或條件不合而 暫緩、放棄

  • 駅(えき) [1]：名 車站
  • で：格助 表 動作場所
  • 友達(ともだち) [0]：名 朋友
  • を：格助 接受 見送る 的 賓語
  • 見送(みおく)る [0]：動I 他動 辞書形 目送
    • 見送った [0]：た形 目送了

まとめ

  • 見かける：沒有刻意尋找，只是 偶然看到
  • 見つける：經過 尋找 或 察覺 後 找到
  • 見当たらない：在目前可確認的 範圍 內 看不到、找不到
  • 見落とす：本應注意到，卻 疏忽漏看
  • 見直す：再次查看，進而 檢查、審視 或 重新評價
  • 見送る：目送 某人離開，也可表示 暫緩 或 放棄
