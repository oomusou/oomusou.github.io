N5 私わたし(わたし)、私あたし(あたし) 我
私(わたし) [0]：代 我私(あたし) [0]：代 我
使い方が分からない時、私に聞いてください。

私(わたし)、私(あたし)

私 可念成 わたし 或 あたし，但 語感 不太一樣。

わたし 則 男女 皆可使用且適用 範圍較廣；あたし 則較口語、親暱，主要由 女性 使用。

N5 何なに(なに)で、何なん(なん)で 什麼方法、什麼原因
何(なに)で [1]：代 什麼方法何(なん)で [1]：代 什麼原因
何で学校に行きますか？

何(なに)で、何(なん)で

何 搭配 格助詞 で 時，可念成 なに，亦可念成 なん，且 意義 不太一樣。

なにで 用於詢問 方法、手段 或 工具；なんで 則用於詢問 原因 或 理由。

N2 ヶ 箇、個、之
1ヶ月3ヶ百円関ヶ原
一ヶ月が過ぎた。

ヶ (箇、個、之)

ヶ 不當作 假名 時，有 三種 讀音，為 替代字。

用於辨識 數量、期間、商品標示 及 地名 中的 ヶ，並依其所代替的 箇、個、之，分別正確讀作 か、こ 或 が。
