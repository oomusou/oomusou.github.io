ようと まいと (不管)

動詞意向形 と 動詞 まいと 可表示 不管。翻譯成 不管 要不要、不管 是不是。

用於以較 正式 且 語氣堅定 的方式表示 無論做或不做 某事，後項的結果、判斷或決定都 不會改變。
