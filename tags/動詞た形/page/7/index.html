タグ : 動詞た形

たり、たりする動作列舉
Vた + り、Vた + りする
毎晩はテレビを見たり、本を読んだりする。

たり、たりする (動作列舉)

動詞た形 り、動詞た形 りする 可選擇 幾個 具有 代表性動作 加以敘述，且動作並 沒有 時間順序，此時 動詞た形 並不代表 過去式，只是 文型使用，時態 由句尾的 する 決定。

Vた N動詞連体修飾
Vた + N = Vて + いる + N
メガネをかけている田中さんはかっこいい。

Vた N (動詞連体修飾)

動詞て形 いる 表 狀態 以 連体修飾 形容 名詞 時，亦可使用 動詞た形 形容 名詞。但 ている 表 現在進行 時，則 不可 換成 動詞た形。

たって即使
Vた + っていA い + く(っ)たってなA + だってN + だって
雨が降ったって行く。

たって (即使)

た形 って 可表示預期事情 沒有發生，或者與 預期相反，為 でも 的 口語。翻譯成 即使。

たら之後
Vた + ら、VたいA い + かったら、VたなA + だったら、VたN + だったら、Vた
二十歳になったら、お酒が飲めます。

たら (之後)

たら 可表示 之後 ，但強調 一旦前句成立，後句才會發生。

たら継起
Vた + らいA い + かったなA + だったN + だった
夏休みになったら、すぐ旅行に行く。

たら (継起)

たら 可表示 継起，用於 前句動作發生了之後，就發生了後句的結果，其中 後句 可有 意志，且可用 過去式 或 未來式，此用法時可用 と 取代，但不能使用 動詞条件形 與 なら，翻譯成 一 就。
