N5 さん 先生、小姐、女士
人名 + さん稱謂 + さん職業 + さん店家名稱 + さん
田中さんは新しい会社で働いています。

さん (先生、小姐、女士)

接尾語 さん 可表示 先生、小姐、女士。

用於 日常會話 及一般 社交場合 中 禮貌地 稱呼他人，也可接在 職業 或 店家 名稱後，適合 初次見面、一般社交、同事 或 不太熟悉的人，不分男女 都能使用，既有 禮貌，又不會顯得 過度正式。

N5 ごろ 大約時間點
時間名詞 + ごろ

ごろ (大約時間點)

時間詞 ごろ 可表示 大約的時間點，漢字為 頃。翻譯成 大約。

用於表示 鐘點、日期、月份、年齡 等 時間名詞 附近的 大約時間點，不表示 一段 模糊的時期。

だらけ (都是)
