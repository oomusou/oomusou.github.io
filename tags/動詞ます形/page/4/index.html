タグ : 動詞ます形

っぱなし持續狀態
Vます ます + っぱなし
電気をつけっぱなしで、寝ちゃった。

っぱなし (持續狀態)

動詞ます形 ます っぱなし 可表示動作實行後 放著不管 的 持續狀態，有 負面 語感，詞性 轉為 名詞。翻譯成 著 就。

なさいませ優雅命令
Vます ます + なさいませ
手をお洗いなさいませ。

なさいませ (優雅命令)

動詞ます形 ます なさいませ 可表示 優雅命令，雖然語法上也是 命令，但包裝了非常厚的 敬意。日常生活 中使用會顯得太過 隆重，甚至有點 做作。

ます形 ます + つつ

次第一 就
Vます ます + 次第 N + 次第 (動作性名詞)
スケジュールが決まり次第、伺いましょう。

次第 (一 就)

動詞ます形 ます 次第だ 可表示一個動作或狀態完成後，隨即進行另一動作或轉變到另一狀態，之後必須接 意志動詞 與 未來式，屬於 生硬 的表達，多用於 商用 或 聯絡。翻譯成 一 就。
