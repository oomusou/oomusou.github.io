N2 っぱなし 重複動作
Vます ます + っぱなし

っぱなし (重複動作)

動詞ます形 ます っぱなし 可表示 重複動作，詞性轉為 名詞。翻譯成 一直。

用於表示某個動作從一段時間前開始 反覆發生，常帶有 動作過度、令人困擾 或 不理想 的 負面 語感。

N4 お 和語動詞 になる 尊敬語
お + 和語Vます ます + になる
部長は帰りました。

お 和語動詞 になる (尊敬語)

お 和語動詞ます形 ます になる 會比 動詞尊敬形 更禮貌。

用於對 長輩、上司 或 客人 的動作表示 尊敬，適用於以 お 接 和語動詞，但 する、いる、見る、寝る 與 来る 等 單音節動詞 不能使用。當使用 尊敬形 可能與 受身形 或 可能形 誤解時，亦可改用 お 和語動詞 になる。
