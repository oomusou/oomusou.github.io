タグ : 授受動詞

てさしあげる我為
A + は + B + に + N + を + Vて + さしあげる
先生にお茶を入れてさしあげました。

てさしあげる (我為)

動詞て形 さしあげる 可表示 施捨 或 邀功，用於 我 為 長輩 或 上司，不適用於當 聽話者 就是 長輩 或 上司 時。

てあげる我為
A + は + B + に + N + を + Vて + あげる

てあげる (我為)

動詞て形 あげる 可表示 施捨 或 邀功，用於 我 為 平輩 或 晚輩，或 他人 為 他人。

あげる我給
A + は + B + に + N + を + あげる
佐藤さんは鈴木さんに花をあげる。

あげる (我給)

あげる 可表示 我 給 平輩 或 晚輩，或 他人 給 他人。 対義語 為 もらう。
