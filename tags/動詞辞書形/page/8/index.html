とか、とかする(動作列舉)
Vる + とか + Vる + とか + する
暇な時大体映画を見るとか散歩するとかしてる。

とか、とかする(動作列舉)

動詞辞書形 とか、動詞辞書形 とか する 可選擇幾個具有代表性的動作加以敘述，此時動作並沒有時間順序，一個動作 亦可，時態由句尾的 する 決定。
