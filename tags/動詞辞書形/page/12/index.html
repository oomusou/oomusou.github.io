ことだ斷定
Vる + こと + だVる + こと + ですVる + こと + である (常用於論文)Vる + こと + であります (常用於演講) Vる + こと + でございます (常用於書信)
趣味は写真を撮ることだ。

ことだ (斷定)

當句子 最後 為 助動詞 だ、です、である、であります 或 でございます 時，則 動詞 需用 動詞辞書形 こと 轉成 名詞。
