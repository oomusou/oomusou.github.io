多い、多く
N + が + 多い多く + の + N
この駅はいつも人が多い。

多い、多く

一般 い形容詞 既可放在 が 之後修飾 名詞，亦可之後接 名詞 直接修飾，但 多い 是 例外，之後 不能接名詞，只能使用 名詞 的 多く。
