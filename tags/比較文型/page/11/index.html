タグ : 比較文型

てたまらない、てたまるか
Vて + たまらない (強烈肯定 的 不得了)Vて + たまるか (強烈否定 的 怎麼可能)
彼に会いたくてたまらない。

てたまらない、てたまるか

てたまらない 與 てたまるか 都源自於 堪る，但 意義 完全不一樣。
