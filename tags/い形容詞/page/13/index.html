愛くるしい

あいくるしい [5]：い形容 可愛到不行。

愛くるしい 用於形容 小孩、動物、表情、仕草 等讓人覺得非常可愛、忍不住想疼愛的樣子，語氣比 可愛い 更 文雅，也比 可愛らしい 更帶有 惹人憐愛 的感覺。

可愛らしい

N5 可愛かわいい可愛的

可愛い

かわいい [3]：い形容 可愛的。

可愛い 是最常用的 可愛，可形容 人、動物、物品、聲音、笑容、動作、服裝 等，對 小孩、動物、物品 使用很自然；對 成人 使用時，常帶有 親近 或 稱讚 語氣，但對 上司、長輩 或 正式場合 要注意 距離感。
