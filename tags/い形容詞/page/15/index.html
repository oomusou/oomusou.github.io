タグ : い形容詞

はいいね稱讚
N + はいいね
A：コーヒー入れましょうか？
B：コーヒーはいいね。

はいいね (稱讚)

名詞 はいいね 可表示 稱讚，雖然有 は 是 否定，但最後 ね 會變成 肯定。翻譯成 很棒 或 我要。

いいです (許可)

當 いいです 前面沒有 格助詞 時，如 てもいいですか 詢問 許可 時，可用 いいです 表示 許可。
