だって、んだもん原因
だって、普 + んだもんだって、Vる + んだもんだって、いA + んだもんだって、なA + な + んだもん だって、N + な + んだもん
だって、電車が故障したんだもん。

だって、んだもん (原因)

接続詞 だって 可表示 原因 。句末經常搭配 んだもん，其中 もん 為 もの 的 縮約，帶有 撒嬌 的 口氣，常用於 女人 與 小孩。翻譯成 就是因為 嘛。
