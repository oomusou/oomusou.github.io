タグ : 副助詞

N3 は 至少
量詞 + は + 肯定
来場者は２０００人はいるようだ。

は (至少)

副助詞 は 前接 量詞 且後接 肯定 時可表示 至少。

は (對比)

副助詞 は 可表示 對比。當一個句子提及 兩個主題，並將此兩個主題加以 對比 時，兩個 主題 都以 副助詞 は 來引導。

では、には、からは (主題)

副助詞 は 可表示 主題。要將 名詞 主題化 時，若其 助詞 為 が 或 は 時可加以 省略，但其他 助詞 則 必須保留。
