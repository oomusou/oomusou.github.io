タグ : 副助詞

か か或
V + か + V + (か)いA + か + いA + (か)なA + か + なA + (か)N + か + N + (か)
行くか行かないかを決めてください。

か か (或)

副助詞 か 可表示 或，從兩個或多的中 選擇 其一，且第二個 か 亦可省略。
