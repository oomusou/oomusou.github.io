タグ : 副助詞

N3 なんて自謙
N + なんて
私なんてこの仕事は無理だよ。

なんて (自謙)

副助詞 なんて 可表示 自謙 ，源自於 輕視，但用於 輕視自己 則 衍伸 為 自謙。翻譯成 我這人。

N3 ずつ各
量 + ずつ
席にお皿を2枚ずつ並べてください。

ずつ (各)

副助詞 ずつ 可表示 各、每、逐一，用來表示相同 的 數量、程度 或 動作 被 平均分配。

たとえ + なA + でもたとえ + N + でも

たとえ でも (即使)

たとえ でも 可表示預期事情 沒有發生，或者與 預期相反，為 でも 的 加強版。翻譯成 即使。
