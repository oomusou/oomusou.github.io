タグ : 格助詞

N3 として 視為
N1 + を + N2 + として
彼女と結婚を前提として交際を始めた。

として (視為)

名詞1 を 名詞2 として 可表示 視為，為 とする 的 て形，翻譯成 把 N1 視為 N2。

N1 として ない 全面否定
量詞 + として + ない疑問詞 + 量詞 + (として) + ない

として ない (全面否定)

格助詞 として 可表示 全面否定，後需搭配 否定 敘述，若搭配 疑問詞 時，亦可省略 として。翻譯成 連一 都沒有。
