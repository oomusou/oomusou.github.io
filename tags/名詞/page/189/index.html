N3 借かり物もの借來的東西、非自己的東西これは借り物だから、大切に使ってください。

借り物

かりもの [0]：名 借來的東西、非自己的東西。

用於表示 向別人借來的物品，強調該物品不是自己的，因此需要 小心使用、按時歸還。也常用在比喻上，表示 暫時擁有 或 不完全屬於自己 的東西。
