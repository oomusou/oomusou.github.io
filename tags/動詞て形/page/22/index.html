てたまらない (不得了)

てたまらない 可形容 自己無法控制 的 情緒 或 身體感受。漢字為 て堪らない，但通常不寫漢字，本意為 無法忍受。翻譯成 不得了 或 非常。

動詞て形 くれ 可表示 強烈命令 對方 為自己辦事，主要為 男性用語，僅用於地位比自己 低 或 平輩，翻譯成 給我做，否定為 ないでくれ。
