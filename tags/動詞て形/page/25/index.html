タグ : 動詞て形

てくる之後再來
Vて + くる
予約をしてくるので、ここで待ってください。

てくる (之後再來)

動詞て形 くる 可表示 先做了某個動作之後再來，相當於 動詞て形 から くる。

てくる (朝我而來)

動詞て形 くる 可表示對方動作由遠而近 朝我而來，翻譯成 來。

ないでくれと (某人不要我做)

動詞ない形 ないでくれと 可表示 引用 命令的 内容，命令者為 長輩、上司 或 同輩，後接 言われる、頼まれる、注意される ……等，翻譯成 某人不要我做，肯定為 てくれと。
