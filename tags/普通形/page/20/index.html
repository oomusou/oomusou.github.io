ないわけがない (不可能不)

普通形 ないわけがない 可表示 不可能不， 白話為 可能性為 100%。本意為 沒有...不的理由，兩個否定 負負得正成為 一個肯定。其中 わけ 為 理由，口語常省略 が 。

だい (疑問)

疑問詞 普通形 んだい 可表示帶有 親近感 的 疑問。多用於 詢問理由、場所、人物 或 狀態 等具體內容，語氣比一般 んだ 柔和，但帶有 男性 或 長輩 口吻。翻譯成 是 呢？。
