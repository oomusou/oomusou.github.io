N1 として ない全面否定
量詞 + として + ない疑問詞 + 量詞 + (として) + ない
君のことを一日として忘れたことはありません。

として ない (全面否定)

格助詞 として 可表示 全面否定，後需搭配 否定 敘述，若搭配 疑問詞 時，亦可省略 として。翻譯成 連一 都沒有。

N1 こそ強調疑問
疑 + こそ
誰こそが犯人なのか？

こそ (強調疑問)

疑問詞 こそ 可表示 強調疑問，用來 突出疑問的 焦點，語氣比 一般問句 更 強。不過這種用法偏 書面 或 修辭 表達，日常會話中較少見。翻譯成 究竟。
