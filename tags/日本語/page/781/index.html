普 + のだったらVる + のだったらいA + のだったらなA + な + のだったらN + な + のだったら
A：明日海へ行く。
B：海へ行くのだったら、山田さんを誘おう。
A：今日は暑いですね。
B：暑いのだったら、エアコンをつけてください。
A：明日までにレポートを出さなければなりませんか。
B：無理なのだったら、金曜日までに出してください。
A：温泉に行きたいのが、どこがいい？
B：温泉なのだったら、白馬がいいよ。

のだったら (引用話題)

普通形 のだったら 可表示 引用話題。此用法時不可用 条件形 、 たら 或 と 取代，為 たら 特有用法。因為用在 引用，翻譯成 的話 。
