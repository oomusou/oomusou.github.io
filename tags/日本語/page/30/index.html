N2 っぱなし 持續狀態
Vます ます + っぱなし
電気をつけっぱなしで、寝ちゃった。

っぱなし (持續狀態)

動詞ます形 ます っぱなし 可表示 放著不管 的 持續狀態，詞性轉為 名詞。翻譯成 著 就。

用於表示某個動作 完成 後，其結果狀態 一直維持 而 未加處理，通常帶有 放任不管 或 不理想 的 負面 語感。

向き、向け

N5 さん、様さま、君くん、ちゃん 先生、小姐、女士、君、同學、小
さん [0]：接尾語 先生、小姐、女士様(さま) [2]：接尾語 先生、小姐、女士君(くん) [1]：接尾語 君、同學ちゃん [1]：接尾語 小
田中さんは今日休みです。

さん、様、君、ちゃん

さん、様、君 與 ちゃん 都可表示 稱謂，但 語感 不太一樣。

一般禮貌 用 さん；正式尊敬 用 様；上位者 稱呼 晚輩 或 部屬 用 君；親暱稱呼 則用 ちゃん。

N4 様 先生、小姐、女士
人名 + 様姓氏 + 様
田中様、お部屋の準備ができました。

様 (先生、小姐、女士)

接尾語 様 可表示 先生、小姐、女士。

用於 飯店、百貨公司、商務書信 或 正式接待 等場合，以比 さん 更 尊敬、鄭重 的方式稱呼對方，但一般職場口語仍常使用 さん 或職稱。
