れようになる能力變化
Vれ + ようになる
やっと日本語が話せるようになりました。

れようになる (能力變化)

動詞可能形 ようになる 可表示 能力變化，本來不會，現在變得會了。翻譯成 變得能。

たほうがいいかな (微婉詢問意見)

N + より、 N + のほうがいい
紅茶より、コーヒーのほうがいい。

のほうがいい (選擇)

名詞 のほうがいい 可表示 主觀 地 選擇，常搭配 格助詞 より。翻譯成 比起 更想要。
