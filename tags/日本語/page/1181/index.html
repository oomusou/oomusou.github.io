でいい、はうい、がいい、たらいい
N + でいい (妥協、謙虛)N + はいい (拒絕)N + がいい (選擇)Vた + らいい (建議、願望)

B：ありがとうございます！部長と同じ、コーヒーでいいです。
A：何か飲む？買ってくるよ。
B：コーヒーでいいよ。
A：コーヒー入れましょうか？

A：社員旅行のことだけど、北海道と沖縄、どっちがいい？
B：北海道がいいです！

でいい、はうい、がいい、たらいい

當 いい 之前搭配不同 助詞 時，會有完全不同的意思。
