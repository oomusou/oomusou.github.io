四大詞性て形變化

2026-07-24

不是只有 動詞 有 て形，事實上 い形容詞、な形容詞、名詞 也有 て形。

動詞

動I

  • いちり -> って
    • 会います -> 会って
    • 立ちます -> 立って
    • 帰ります -> 帰って
  • みにび -> んで
    • 飲みます -> 飲んで
    • 死にます -> 死んで
    • 遊びます -> 遊んで
  • き -> いて
    • 書きます -> 書いて
  • ぎ -> いで
    • 急ぎます -> 急いで
  • し -> して
    • 貸します -> 貸して
  • 例外
    • 行きます -> 行って

動II

  • え段 -> て
    • 開けます -> 開けて

動III

  • 来ます -> 来て
  • します -> して
  • 勉強します -> 勉強して

い形容詞

  • いA -> いA い + くて
    • 暑い -> 暑くて
  • 例外
    • いい -> よくて

な形容詞

  • なA -> なA + で
    • 便利 -> 便利で

名詞

  • N -> N + で
    • 学生 -> 学生で
